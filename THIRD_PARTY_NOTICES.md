Maxsurf must be separately installed and appropriately licensed for automation.
This repository contains no Bentley binaries, manuals, criteria libraries,
generated COM wrappers, example designs, or training document collection.

Runtime dependencies are listed in requirements.lock. The MCPB build includes
their installed distribution metadata and license files without replacing their
licenses with this project's MIT license. The generated
THIRD_PARTY_INVENTORY.json records each bundled distribution and its declared
license metadata. Read its corresponding server/lib/*.dist-info license files.
Non-runtime compiled help files (.chm) and bytecode caches are omitted; license
files are retained. Distribution RECORD metadata may mention those omitted
upstream help files. No third-party library code is rewritten by this builder.

The extension icon is an original project asset, not a Bentley or Claude logo.
